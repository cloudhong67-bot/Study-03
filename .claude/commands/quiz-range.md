`prisma/data/questions.json`에서 id가 $1번부터 $2번까지인 문제를 검토하고, 난이도와 정답 위치(`answer_index`)가 고르게 분포하는지 알려 줘.
이 명령은 **점검만** 한다. 파일은 수정하지 말고, 고칠 점은 제안으로만 적어 줘.

## 검사 범위

- 시작 id: `$1`, 끝 id: `$2` (둘 다 포함)
  - 문제는 배열 위치가 아니라 문제의 `id` 값으로 고른다.
  - 둘 중 하나라도 비었거나 정수가 아니거나, 시작 id가 끝 id보다 크면 검사하지 않는다. 사용법(`/quiz-range 1 10`)과 JSON에 있는 id의 최솟값·최댓값을 보여 준 뒤 멈춘다.
  - 범위에 해당하는 문제가 하나도 없으면 위와 같이 id 범위를 보여 준 뒤 멈춘다.
  - 범위가 JSON의 id 범위를 일부 벗어나면, 있는 문제만 검사하고 요약에 실제 검사한 id 범위를 적는다.

## 진행 방법

1. Node로 JSON을 읽어 id로 거른 뒤 id 오름차순으로 정렬하고, 아래 값을 계산한다. 줄 단위 grep은 쓰지 않는다.
   - 난이도(`easy`/`medium`/`hard`)별 문제 수: 범위 전체 및 카테고리별
   - 정답 위치(0–3)별 문제 수: 범위 전체 및 카테고리별
   - 같은 정답 위치가 id 순서로 **3문제 이상 연속**되는 구간
2. **난이도 분포**를 CLAUDE.md "Data and migrations"의 규칙에 비춰 판단한다.
   - 각 카테고리는 easy 3 · medium 4 · hard 3이어야 한다(카테고리 최대 점수를 217로 맞추기 위해).
   - 범위가 카테고리의 문제를 **전부** 포함할 때만 3·4·3 위반으로 판정한다. 일부만 포함하면 "부분 포함"으로 표시하고 개수만 보여 준다. 카테고리 전체 문제 수는 JSON 전체에서 센다.
   - `difficulty` 값이 세 가지 중 하나가 아니면 오류로 표시한다(seed가 거부한다).
3. **난이도 적정성**: 문제마다 표기된 난이도가 14세 이상 대상(PRD)에 비춰 적절한지 본다. 지식의 보편성(교과 과정에서 배우는가), 보기의 헷갈림 정도, 연도·수치 암기가 필요한지를 근거로, 어긋난다고 보이는 문제만 `조정 검토`로 짚는다.
4. **정답 위치 분포**를 판단한다.
   - 위치별 개수가 고른지 본다. 기대값은 문제 수 ÷ 4이다. 한 위치가 기대값의 2배를 넘거나 0이면(문제가 8개 이상일 때) `편중`으로 판정한다.
   - 3문제 이상 연속된 같은 정답 위치를 짚는다.
   - 보기가 수치 순서(연도, 온도, 크기 등)로 놓인 문제는 CLAUDE.md 규칙대로 순서를 유지해야 하므로 정답 위치를 옮기라고 제안하지 않는다. 표에 `수치 순` 표시만 한다.
5. `answer_index`가 0–3 밖이거나 `options`가 4개가 아니면 오류로 표시한다(DB CHECK 제약이 거부한다).

## 출력 형식

한국어로, 아래 순서대로 출력한다.

1. **요약**: 요청 범위와 실제 검사한 id 범위, 검사한 문제 수, 포함된 카테고리(전부/부분 포함), 오류 수, 난이도 조정 검토 수, 정답 위치 판정(`균형` / `편중`)
2. **문제 목록** (표, id 오름차순):

   | id | 카테고리 | 난이도 | 정답 위치 | 정답 | 비고 |
   |----|----------|--------|-----------|------|------|

   - 비고: `수치 순`, `조정 검토(→ medium)`, `연속 3`, `오류: …` 등
3. **난이도 분포** (표): 카테고리별 행과 합계 행, 열은 easy · medium · hard · 판정(`OK` / `위반` / `부분 포함`)
4. **정답 위치 분포** (표): 카테고리별 행과 합계 행, 열은 0 · 1 · 2 · 3 · 판정(`균형` / `편중`)
5. **보완 제안**: 항목마다 한 줄로 제시한다.
   - 난이도 위반·조정 검토: 어느 문제를 어떤 난이도로 바꿀지와 그 근거. 3·4·3을 깨지 않도록 같은 카테고리 안에서 맞바꾸는 방법을 우선 제안한다.
   - 정답 위치 편중·연속: 어느 문제의 보기를 어떻게 재배치해 정답을 몇 번 위치로 옮길지(수치 순 문제는 제외)
   - 제안할 것이 없으면 "보완 필요 항목 없음"이라고 적는다.
